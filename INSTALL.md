# Installing rosella

This archive holds one binary, `rosella`. Put it on your `PATH`:

```bash
install -m 755 rosella /usr/local/bin/
rosella --version
```

Read mapping, gene calling and the marker search are built in, so nothing else is needed.
`--gpu` runs on Metal. Metal ships with macOS.

The documentation is at https://rhysnewell.github.io/rosella.
